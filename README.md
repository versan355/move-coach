# MOVE

Лендинг тренера с двумя вариантами дизайна, 15 разделами, кабинетом ученика, загрузкой домашних заданий и серверной интеграцией Telegram.

Подробная передача проекта, текущие ограничения, проверка и подключение бота: [HANDOFF.md](HANDOFF.md).

```text
npm ci
npm run dev -- --port 4175
npx tsc --noEmit
node --test scripts/telegram.test.mjs scripts/api.test.mjs
npm run build
```

Для локальной D1 сначала собрать проект, затем выполнить каждую миграцию из `drizzle/` по порядку:

```text
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/ИМЯ_МИГРАЦИИ.sql
```

Node.js 24. D1 и R2 объявлены в `.openai/hosting.json`. Реальные секреты задаются только в окружении. Новую копию для другого преподавателя регистрировать как отдельный проект Sites с новой идентичностью; не публиковать её поверх исходного проекта.

## GitHub Pages

Публичный лендинг: https://versan355.github.io/move-coach/

Статическая сборка находится в docs/. GitHub Pages публикует main → /docs. Для обновления выполните npm run build:pages, сохраните исходники и docs/ в коммите и отправьте его в main. Настройка base: /move-coach/ сохраняет пути к ресурсам при публикации из репозитория.

Кабинет, заявки и сдача ДЗ открываются в отдельно размещённой защищённой версии: https://move-coach-studio-1110.linenmarigold2.chatgpt.site/ . Эта демонстрационная версия требует входа через ChatGPT и сейчас доступна владельцу проекта. Telegram-бот не подключён. Статическая страница не имитирует отправку форм и не собирает файлы.

Для собственной серверной версии нужно зарегистрировать отдельный проект и настроить D1/R2. Идентификатор исходного проекта удалён из конфигурации этой копии.
